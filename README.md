# 광안 3D — 정식 공개 상설 야간 축제

- **항상 밤 모드**: 낮에도 야경을 유지합니다.
- **상설 공연**: 불꽃축제와 드론쇼가 계속 진행됩니다.
- **종이배 무제한**: 시간·일일 횟수 제한 없이, 메시지 최대 30글자. 같은 채널에 5초 표시됩니다.
- **테스트 버튼 제거**: 공연 미리보기·개발용 동행·종이배 테스트 메뉴 제거.
- **모바일**: 기존 터치 카메라 확대/이동 기능 유지.
- **BGM**: 상설 공연 중 재생됩니다. 모바일은 입장 후 오디오 활성화됩니다.

## 실행
```bash
npm install
npm start
```
`http://localhost:3000` 또는 Render 공개 주소로 접속하세요.

## GitHub/Render 갱신
압축을 풀어 **최상위** `server.js`, `package.json`, `render.yaml`과 **`public/` 아래** `index.html`, `game.js`, `style.css`를 기존 저장소의 동일 경로에 덮어씁니다. GitHub 커밋 후 Render 자동 배포가 끝나면 기존 공개 URL이 그대로 적용됩니다.

주의: Render 서버 인스턴스가 재시작되면 접속자 연결은 끊기며 재접속이 필요합니다.


## 흰 화면 수정
정식 버전에 없는 sitTogether/demoFriend/demoShow/demoWish/demoStop 버튼의 클릭 이벤트 연결 코드를 제거했습니다.


## 모바일 HD 화질 개선
- 모바일 렌더러 해상도 제한을 1.25배에서 최대 2.5배로 상향했습니다.
- 실제 기기 DPR을 사용하고 프레임버퍼 최대 500만 픽셀로 과부하를 방지합니다.
- 세로 화면 카메라, 확대/축소, 기존 상시 야간 축제, 종이배 5초 메시지는 유지됩니다.
- GitHub 정식 저장소의 `public/game.js`와 `public/index.html`을 교체하면 됩니다.
- 고화질 모드는 일부 저사양 휴대폰에서 프레임 저하나 발열을 일으킬 수 있습니다.
